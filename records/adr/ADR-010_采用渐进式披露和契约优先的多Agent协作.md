# 采用渐进式披露和契约优先的多 Agent 协作

> 版本：0.1  
> 最后更新：2026-09-05  
> 依赖文档：无

> 论证完整性：不足；当前仅保留决策结论和部分背景，候选方案、具体代价、影响范围和关联设计需要在对应专题设计时补全。

## 背景

项目模块和文档多，完整上下文容易爆炸；并行 Agent 易越界。

## 决策

先总体设计/模块/接口，再拆任务；Agent只读必要文档；统一 handoff。

## 决策原因

该决策与 LiveRelay 当前的隐私、长期恢复、六周交付或多 Agent 协作约束一致。

## 代价

需要额外维护抽象、接口、文档或迁移边界。

## 反转条件

项目若极小可简化，但 LiveRelay 目前继续采用。

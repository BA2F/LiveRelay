# SQLite 与原始资料 Blob 分离

> 状态：草案
> 版本：0.1  
> 最后更新：2026-09-05  
> 依赖文档：无

> 论证完整性：不足；当前仅保留决策结论和部分背景，候选方案、具体代价、影响范围和关联设计需要在对应专题设计时补全。

## 背景

原始照片/PDF/音视频可能增长到 GB 级。

## 决策

SQLite 存结构化数据/索引；原始资料独立加密。

## 决策原因

该决策与 LiveRelay 当前的隐私、长期恢复、六周交付或多 Agent 协作约束一致。

## 代价

需要额外维护抽象、接口、文档或迁移边界。

## 反转条件

若未来单文件 DB 在性能、备份和流式场景证明更优，可复议。

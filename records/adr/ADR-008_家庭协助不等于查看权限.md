# 家庭协助不等于查看权限

> 状态：草案
> 版本：0.1  
> 最后更新：2026-09-05  
> 依赖文档：无

## 背景

适老化需要家人帮助，但家庭本身也可能是隐私风险。

## 决策

录入协助与查看权限分离。

## 决策原因

该决策与 LiveRelay 当前的隐私、长期恢复、六周交付或多 Agent 协作约束一致。

## 代价

需要额外维护抽象、接口、文档或迁移边界。

## 反转条件

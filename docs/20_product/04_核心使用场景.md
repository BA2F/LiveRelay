# 04_核心使用场景

## 产品路径

LiveRelay 的日常使用从记录开始，不要求用户先想好分类或交接方案。资料先安全留下来，再逐步整理成可理解、可查找、有来源和历史的信息卡片；临时失能和身故后的有限交接是基于日常积累的后续场景。

```text
原始资料 → 识别文本或人工输入 → 待确认草稿 → 本人确认 → 正式卡片
     └────────────────── 来源锚点和修订历史 ──────────────────┘
```

## 首版日常使用

1. 打开应用时若 Vault 处于锁定状态，先解锁。默认进入记录页，可在设置中调整启动首页。若开启“启动后直接快捷记录”，则在 Vault 已解锁后弹出快捷编辑框；文字、拍照、录音、录像均可从中开始，不在锁定状态暂存明文。
2. 原始文字、照片、录音、录像进入加密保存，记录页可查看最近原件和待确认草稿。照片/相册输入可经本地 OCR 得到文本和位置；音视频首版先保存并回看原件，不要求自动转写或理解，仍可由用户手工整理。
3. 整理工作台按“原件及定位 → 识别/输入文本 → 草稿卡片”组织，桌面端可并排、手机端可分步。云 AI 是可选路径：每次只在用户允许本次调用后，处理本次选中资料的脱敏内容；不用 AI 仍可手工整理。
4. AI 结果先成为可编辑、可保存的草稿卡片。大草稿可逐步拆分，确认一张小卡片，其余继续留为草稿；本人手动输入的一条完整信息可以直接成为正式卡片，并保留本人输入的来源。
5. 用户在卡片页查找和维护信息。单条卡片可引用原件具体片段，移动房产证等同一事项的变化形成该卡片新修订，旧位置留在历史。可选盒子负责收纳，组合卡片负责一起呈现；两者都不复制或扩大成员权限。原件可在警示关联影响后明确删除，相关卡片显示“原件已删除”。

## 密码与人物

密码库是同一 Vault 中的专门视图，条目同时可作为卡片或经典列表行查看，背后只有一份信息。首版支持条目创建、编辑、删除、搜索、安全显示与复制、加密保存和导出恢复、Edge 原生 CSV 导入及中文词组口令生成。Secret 默认遮挡；解锁后可主动显示或复制单条密码，批量导出前再次验证。旧密码版本加密保存；普通删除与清除当前 Vault 中的条目及历史 Secret 是不同操作。

人物以类似通讯录的列表与详情页呈现，提供称呼、联系方式、关系类型及关键说明，并区分事实、个人看法和建议。关系网状图属于后续方向。

## 首版交接演示

首版人工模拟临时失能和身故状态，Executor View 仅按策略呈现允许的信息，并明确标注为模拟，不提供真实状态核验或自动交接。新卡片和原件默认仅本人可见；任何向接收者释放的层级都需本人明确设置。信息可见不等于银行、继承等正式法律处置权。

## 当前与后续边界

当前完整自动整理链路以照片、本地 OCR、人工标记和获授权的云 AI 为主。音频转写、视频内容提取、桌面本地模型、外部 Agent 连接器、密码自动填充与浏览器扩展、独立密码管理 App、KeePass 数据库导入、真实交接核验和复杂组合凭证均不作为首版完成条件。卡片盒子、组合卡片等已确认产品行为的具体实现里程碑仍须与开发范围核对。

领域与来源规则分别由 [核心实体与资料关系](../30_design/domain/01_核心实体与资料关系.md)、[人工确认与 AI 推断](../30_design/provenance/03_人工确认与AI推断.md) 和 [信息释放与交接策略](../30_design/domain/04_信息释放与交接策略模型.md) 维护；加密与权限实现细节不由本文定义。

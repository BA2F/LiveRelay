## 首版重点

- Vault/Crypto 关键规则的单元测试；
- OCR → AI Privacy → Vault 的集成闭环；
- `.lvault` 导出/导入一致性和损坏处理；
- Token/Schema 校验；
- LifeState/Handoff 的简化演示链路；
- 从图片导入到 Executor 查看允许信息的端到端路径。

当前自动化测试已覆盖中文词组口令、VMK 封装/错误密码、SQLCipher、Repository 修订和敏感标记、Edge CSV、加密 Blob、`.lvault` 往返与篡改、AI Privacy Token 规则、OpenAI-compatible 请求边界、生命周期和基础 Widget。媒体插件与完整 UI 流程主要依赖运行验证。

## 安全与隐私

至少覆盖：

- 错误密码；
- 密文或导出文件被篡改；
- nonce/随机性使用错误；
- 数据库/磁盘/日志/临时目录泄漏；
- 剪贴板、截图和后台缩略图风险；
- AI/OCR 失败时不丢原始资料。

## 恢复与迁移

- 崩溃、中断、半写入；
- 格式升级保留旧版本测试样本；
- 数据迁移不能只测试“新版本能打开自己生成的数据”。

## 尚未完成的验证

- 实体 Android 设备上的强生物识别、相机和厂商 ROM 权限行为；
- 真实 OpenAI-compatible Provider 的网络、超时、限流和 Schema 差异；
- 断电、磁盘满、恢复替换中断和超大输入压力测试；
- Android 7～15 设备矩阵、横屏、真人 TalkBack 听读与更多字体/屏幕组合；
- 剪贴板生命周期、系统截图/后台缩略图等隐私体验的专项验收；
- 正式发布证书、Play 商店打包和供应链扫描。

## 原则

测试应从威胁模型、契约和真实功能中长出来。每次格式或 schema 升级必须增加旧版本样本；真机或真实服务未验证的能力不得仅凭单元测试标记为完成。

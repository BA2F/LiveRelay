## 这个版本是什么

结束 MVP 里程碑序列，正式版本从 beta 开始。相对 MVP0.4，这个版本带来的是一整轮桌面重造加互通体系：

- 桌面三区工作台（左栏导航、对象标签页、状态条、右键菜单与快捷键）和 VSCode 式右栏（来源／历史／引用只读透镜）。
- 设备间搬运：整库导出到介质目录或云端（WebDAV）、整库替换导入、原件按卷增量。云端走标准 WebDAV，阿里云 1:N 云盘已部署。
- 合并导入（B 模式）：同血脉的两台设备按卡片修订合并；两边都改过的卡片保留本机版并标记，可一键采用另一台设备的版本；删除冲突按方向处理；密码库与身份资料不参与合并（界面明示）。
- 授权与确认模型：AI 外发、语音上传首次确认后记住、可收回；不可逆操作仍逐次确认。
- 卡片附件直加、引用搜索式选择、建库默认自定密码、正式入口去除"模拟／演示"字样。
- 英语界面试点（引导／建库解锁／主外壳／记录页，中英可切换）。
- Android 图标为产品标识；安装包改为 arm64 单架构并启用正式签名。

## 安装与升级

- **Android（arm64）**：从 MVP0.4 及更早版本升级必须先卸载旧版（签名变更，不可覆盖安装）。旧版数据在卸载时清除，请先导出：旧版「我的 → 本地分层备份」导出数据库包与原件补充包到设备外，装好本版后用同一入口恢复（解锁凭证随库恢复）。
- **Linux（x86_64）**：解压 `LiveRelay-v1.0.0-beta.1-Linux-x86_64.tar.gz`，进入目录运行 `./live_relay`。构建基线 Ubuntu 22.04／glibc 2.35；全部 ELF 最高依赖 GLIBC 2.34／GLIBCXX 3.4.29／CXXABI 1.3。运行需要 GTK3、libsecret、libstdc++ 与桌面图形环境（视频播放另带 libmpv，已随包提供）。

## 验证

- 静态分析无问题；314 项自动化测试通过（含 B 模式引擎单测、同库两副本合并往返、控制器级往返）。
- 桌面原生套件通过：工作台 16 项、生产入口启动、关闭、搬运闭环。
- 人工走查：小米13（Android 13）安装本分支构建完成手机端调试；模拟器完成中英文引导、建库、解锁与主界面全流程走查（英语试点）。
- APK 用 aapt2 核对包名、版本与 ABI 构成（仅 arm64-v8a），apksigner 验证 v2 签名与证书指纹。
- Linux 包在隔离 Ubuntu 22.04.5 rootfs 内构建并完成全 ELF ABI 审计（最高 GLIBC 2.34）；bundle 不含调试元数据（逐个检查）；最终 bundle 在同一隔离环境的 Xvfb 下完成启动冒烟（应用存活、Impeller 与 media_kit 正常加载；无钥匙环时出现预期的 Secret Service 警告）。
- 发布页三个附件的大小与 SHA-256 已与本地逐一核对一致（见 artifacts.json）。

## 已知限制

- Windows 未验证；低资源设备与更多 Android 机型待覆盖。
- 正式安全复核尚未进行（本版本为 beta）。
- 英语覆盖为试点：深层页面、引擎错误文案、写库文案仍为中文；中文词组口令、语音识别、OCR 不随界面语言切换。
- 云端 HTTPS（证书）、正式客户账号、摇篮服务、分屏与命令面板未包含在本版本。

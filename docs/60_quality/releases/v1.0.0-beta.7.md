## 这个版本是什么

在设置主密码的地方加一条强度提示，其余内容与 beta.6 相同。

## 密码强度条

- 两处显示：创建资料库页的「主密码」下方，设置 → 安全 → 更改密码页的「新主密码」下方。
- 三档：

| 档位 | 显示 |
| --- | --- |
| 弱 | 左侧一条红色实心，其余两条中空，右侧写「弱」 |
| 中 | 两条黄色实心，最后一条中空，右侧写「中」 |
| 强 | 三条绿色实心，右侧写「强」 |

- 空密码不显示。中文词组生成模式不显示。
- 强度按字符类别估算位数，重复字符和顺序字符只计一次，包含常见口令时直接判弱。估算的数字不显示：用户输入的密码常有规律，公式会高估。
- 提示条不改变「至少 8 个字符」的现有规则，只做建议。

## 相对 beta.6 的其他变化

- beta.6 修好了 Android 启动崩溃，本版本包含该修复。
- Linux 包不再混入 101 MB 的 `kernel_blob.bin`。beta.6 的 Linux 包带了这个调试产物，体积因此偏大；本版本已清理。
- Android Release 包使用 `flutter build apk --release`（不带 `--no-pub`）构建，保证插件注册类按 release 模式生成。

## 已知限制

- 强度估算只看字符构成，不查在线泄露库；它给的是方向，不是保证。
- 解锁、建立资料库和交接流程没有在本轮走查。
- `ux_flow` 集成测试仍在建库等待处失败，早于本版本存在。
- Windows 人工走查未做。
- 邮件仍带同一个 WebDAV 账号密码；云端为 IP+HTTP；服务端可见邮件里的取件码。取舍与 beta.4 相同。

# LiveRelay · MVP 0.2 — 日常记录与交接准备

构建与验证完成于 2026-10-02。发布本次已验证的原 APK，保留全部四个主导航和暖色品牌。

## 改进

- 搜索隔离：无结果不再清空首页最近内容，刷新后查询与结果保持一致。
- 内容优先的轻量记录：“先保存”真实加密保存为待整理草稿；本人可明确确认保存。编辑同一卡片追加修订，离开未保存编辑可加密保留。
- 首页重排、可处理的待整理入口、全部原件列表及搜索/类型筛选、查看/整理双视图、来源片段与完整修订历史。
- 卡片/密码删除撤销和回收恢复；首次使用与锁定时均可进入备份恢复。恢复前核对已认证的时间、数量及替换影响，设置显示成功导出记录。
- 中文 AI 外发检查、原文/发送文本对照、单次授权及独立手工整理路径，AI/OCR 结果仍先成为草稿。
- 交接准备总览、六级授权的精确实际输出、默认遮挡密码和独立本机模拟页。
- 明暗主题、小屏、大字体、键盘滚动、读屏标签、触控目标和对比度修复。
- 修复 Android 原生 HKDF 空 salt 导致的备份导出错误；旧 MAC 等价测试通过。

## 兼容性与验证

数据库 schema v4、Header/Blob v1、`.lvault` v1 保持兼容；不改变“基本信息截取正文”及各等级原有释放规则。全部已有授权层级保留。

静态分析无问题，38 项测试全部通过；Android 16 完整 UI 集成回归、真实端侧 ML Kit OCR、原生文件选择器导出及空库/锁定恢复、320dp/200% 字体/系统深色/真实键盘下保存、覆盖安装和冷启动通过。AI 回归使用离线测试 Provider，未向真实云服务发送资料。

## 使用与边界

同包名、同证书可覆盖旧版安装；升级时不要卸载旧应用，卸载会清理本机资料库。保管口令，定期将加密备份另存到设备外并验证恢复。Debug 测试包使用独立 `.verification` 包名。

真实 AI Provider、实体生物识别与媒体硬件、真人 TalkBack 听读、恢复中断和大规模压力仍未完成验收。交接仍为本机模拟及演示执行人，不提供真实接收者或自动交接。使用 Android Debug 证书，仅供侧载验收。

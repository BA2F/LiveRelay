# 文档维护与可持续性规则

> 状态：当前有效  
> 版本：0.3  
> 最后更新：2026-09-06  
> 依赖文档：无


## 1. 当前原则

结构可以简化，知识不能静默丢失。

- 当前有效结论 → `docs/`
- 决策原因 → `records/adr/`
- 讨论过程 → `notes/`
- 当前 AI 快速上下文 → `memory/`
- 已退出事实流但仍需保留 → `archive/`

## 2. 防止漂移

在真实里程碑/版本结束时检查：

- 实现是否违反冻结契约；
- 设计是否与代码明显不一致；
- 已完成 Task 是否有必要 Handoff；
- 已实施 ADR 是否回写 docs；
- memory 是否与 docs/tasks 一致；
- 数据格式/迁移是否保留测试样本。

## 3. Git 与快照

重要版本使用 Git Tag，并保留简短状态快照。旧 ADR 不删除；被替代时保留历史链。

## 4. 外部事实

法律、产品能力、依赖版本、外部 API 等会变化的信息必须记录来源和核验日期，必要时重新核验。

## 5. 可持续性底线

LiveRelay 的长期数据格式、恢复方式和迁移能力不应依赖单一 App、单一 AI 提供商或未来仍然存在的开发者。

# 00_项目总览

> 状态：已确认  
> 版本：0.1  
> 最后更新：2026-09-05  
> 依赖文档：无

LiveRelay 当前为临时项目名。

一句话定位：面向中文社会环境、所有年龄可使用且老年阶段价值达到峰值的本地优先人生信息连续性与交接系统。

第一版面向年轻用户本人。后续增加适老化和年轻人协助父母/祖父母整理。

第一版核心场景：记录物品/文件位置；记录账户/密码/资产线索；保存原始资料；本地 OCR + 人工字段标记；敏感字段本地 Tokenization 后调用云 AI；失能有限释放；逝者→生者接手闭环。

项目同时用于实训交付和简历，强调 AI 应用、隐私工程、跨平台、软件工程设计。

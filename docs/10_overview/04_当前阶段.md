## 当前实现事实

- Flutter 3.47，Dart SDK 约束 `^3.13.2`。平台目录为 `android/`、`linux/`、`windows/`。
- Android `minSdk` 24，`targetSdk` 36。
- Argon2id 派生密码密钥，AES-256-GCM 封装随机主密钥，SQLCipher 整库加密。
- 数据库 schema 版本 5。主界面新建 Header 格式 3，保留格式 1 和 2 的读取路径。
- AES-256-GCM 加密原始 Blob，以及带清单认证的 `.lvault` 导出和原子恢复。
- 卡片、修订历史、拆分和组合、搜索、草稿确认与来源标记。
- 同一资料库中的密码库、历史版本、回收和清除、Edge CSV 导入。
- 图片、录音和录像导入，现场采集，端侧中文 OCR，媒体回看。
- 行级敏感标记、Tokenization、单次授权、OpenAI 兼容 Provider 与本地复原。
- 生命状态、释放策略和接收者视图。
- 按接收者分份的取件码交接包。摇篮计划 v2 按每人的草稿发信。
- Android Keystore 生物识别密钥槽。桌面端保留核心替换边界。
- 密码强度提示：创建资料库页和更改密码页显示三档强度。

## 已验证

- `flutter analyze` 无问题。`flutter test` 347 项通过、3 项跳过、0 失败。
- Android release 包在小米 13（Android 13）上冷启动到解锁页，无崩溃。
- Linux 包在 Ubuntu 22.04.5 隔离 rootfs 构建，ABI 审计通过。bundle 在 Xvfb 中运行 20 秒未退出。
- 云端摇篮服务：计划 v2 被接受，测试邮件结果文件写入，请求文件删除，真实 SMTP 发信成功。
- 密码强度条：模拟器上逐档确认三档显示，实体机确认可见。

## 当前阶段

产品定位和核心原则已基本收敛，首个 Flutter/Android MVP 已可运行。项目从纯设计期进入**实现收敛、真机验证与事实回写阶段**。

MVP 源码位于 `work/code/live_relay/`，已通过提交 `4b4032e` 纳入 Git 基线。当前仍不是带版本 Tag、正式签名或商店发布的生产版本。

## 当前实现事实

- Flutter 3.47 / Dart 3.13 单工程，Android 首发，最低 API 24；
- Argon2id 派生密码密钥、AES-256-GCM 封装随机 VMK、SQLCipher 整库加密；
- AES-256-GCM 加密原始 Blob，以及带清单认证的 `.lvault` 导出和原子恢复；
- 卡片、修订历史、拆分/组合、搜索、草稿确认与来源标记；
- 同一 Vault 中的密码库、历史版本、回收/清除、Edge CSV 导入；
- 图片/录音/录像导入和现场采集、端侧中文 OCR、媒体回看；
- 行级敏感标记、Tokenization、单次授权、OpenAI-compatible Provider 与本地复原；
- Active / Incapacitated / Deceased 演示状态、释放策略和 Executor View；
- Android Keystore 生物识别密钥槽已接入，桌面端核心替换边界已保留。

## 已验证

- `flutter analyze` 无问题；
- 25 项自动化测试全部通过；
- Android 16 模拟器完成数据库 v1 → v4 迁移、安装、冷启动和主要媒体/OCR流程验证；
- Release APK 已构建并通过 APK Signature Scheme v2 校验；本地验收包使用 Debug 证书签名，仅用于侧载演示。

## 当前优先顺序

1. 真机验证指纹、相机、录音、视频和文件权限；
2. 用受控测试账号联调真实 AI Provider；
3. 做安全复核、崩溃/恢复测试和迁移样本固化；
4. 配置正式签名、可复现构建和首个版本 Tag；
5. 根据真实使用反馈调整 MVP，而不是提前扩张未来功能。

## 当前冻结项

除非真实开发暴露问题，不再新增 governance、模板、Skill 或新的顶层工作流目录。MVP 内部端口是当前实现事实，但尚未冻结成外部公共契约。

## 当前完成标准

当前阶段完成标准是：代码、设计、测试证据和发布边界保持一致；未做真机或真实服务验证的能力必须明确标注，不得因为“已编译”写成“已生产验证”。

# 03_核心设计原则

> 状态：已确认  
> 版本：0.1  
> 最后更新：2026-09-05  
> 依赖文档：无

1. Local-first；2. 原始资料高于 AI；3. Provenance 可追溯；4. 历史不被摘要覆盖；5. 最新不等于最可信；6. 协助不等于查看；7. 信息可分级释放；8. Crypto Agility；9. 运行时 DB 和 Blob 均为密文；10. 成熟库优先，不自创密码算法；11. UI/DB/AI/OCR/ASR/Crypto 实现可换；12. 业务不绑死具体实现；13. 恢复/导出不做未来付费墙；14. 官方与社区信息分离；15. 接口冻结后再多 Agent 并行。

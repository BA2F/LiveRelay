# 模块索引

> 状态：已确认\
> 版本：0.5\
> 最后更新：2026-10-02\
> 依赖文档：无


当前 MVP 在单个 Flutter package 中完成逻辑模块划分。下表描述 **as-built 归属**；“已实现”不表示已经拆成独立 package，也不表示接口已冻结给第三方。

| 逻辑组件/能力 | 当前职责与代码归属 | 物理状态 | 契约状态 |
|---|---|---|---|
| UI | `presentation/`：Material 3 页面、对话框、Design System atoms | 已实现 | 无公共 UI 契约 |
| Application | `application/app_controller.dart`：解锁会话、全量快照/独立搜索、来源/恢复和备份核对；`release_preview.dart` 共用实际释放投影 | 已实现 | App 内部 API |
| Life Core | `core/domain/`：卡片、凭据、原件、状态和策略语义 | 已实现 | 纯 Dart 内部模型 |
| Vault | `VaultRepository` + `SqliteVaultRepository`：结构化数据、策略、历史、来源、回收/恢复、备份导出审计 | 已实现 | MVP 内部端口 |
| Crypto | `core/security/`：Argon2id、VMK 封装、中文词组口令 | 已实现 | 格式 v1，未对外冻结 |
| Database | `infrastructure/persistence/`：Drift + SQLCipher schema v4 | 已实现 | 迁移边界已使用 |
| Blob | `infrastructure/blob/`：AES-GCM 原始资料存储 | 已实现 | Blob 格式 v1 |
| Backup | `infrastructure/backup/`：`.lvault` 清单、认证、恢复 staging | 已实现 | 容器格式 v1 |
| Provenance | SourceKind、CardRevision、完整来源片段、原件链接和关系 | MVP 已实现 | 尚非独立模块 |
| Capture | `capture_page.dart` + image/record/file plugins | Android 已实现 | 平台行为未冻结 |
| OCR | `OcrProvider` + Google ML Kit 中文实现 | Android 已实现 | MVP 内部端口 |
| AI Privacy | `core/ai/`：Tokenization、校验、Rehydration | 已实现 | 纯 Dart 内部能力 |
| AI Provider | `AiProvider` + OpenAI-compatible HTTPS 实现 | 已实现，真实服务待联调 | MVP 内部端口 |
| Lifecycle | `core/domain/lifecycle.dart` + repository events | 演示实现 | 仅本地模拟 |
| Handoff | ReleasePolicy + 准备总览/接收者精确预览/独立模拟 | 演示实现 | 不含现实核验链 |
| Platform | Android 生物识别、相机、媒体、文件适配 | Android 已实现 | 桌面适配待实现 |

## 进一步拆成独立 package 的条件

只有具备以下多数条件后才拆分 package 或新增详细模块文档：

- 职责和非职责已经明确；
- 上下游关系明确；
- 已出现第二个客户端或独立复用需求；
- 关键输入输出已经足够明确；
- 可以独立测试或独立替换；
- 能够给 Agent 清楚的修改边界。

当前不为已在代码中清晰表达的目录机械复制说明文档。跨模块格式、稳定契约和安全边界仍应写回正式设计。

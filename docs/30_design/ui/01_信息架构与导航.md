## 当前方向

首版移动端主导航先采用“记录 / 卡片 / 密码库 / 交接”。人物关系通过卡片页筛选和人物详情进入；设置放在菜单中，不占用主导航。记录页承接原始资料、待确认草稿和新建入口；密码库仍是同一 Vault 的专门视图。交接入口中的 Executor View 是否切换为独立模式，仍需细化。

移动端和 Desktop 可以采用不同导航方式，不要求像素级同构。

人际关系首版使用类似通讯录的列表与详情页，关系网状图后续再考虑。

## 启动与快捷记录

默认首页先设为记录页，但用户可以在设置中更改启动后的首页。记录页首版显示最近的原始资料与待确认草稿，并提供醒目的“新建记录”入口；它不是快捷编辑框。其他一级入口及详细布局尚未确定。

“启动后直接快捷记录”是另一项可开关设置：开启后，若 Vault 锁定则先通过口令或设备生物识别解锁，再弹出快捷编辑框；未解锁时不暂存明文记录。编辑框提供文字、拍照、录音、录像四个入口，不等同于仅将首页设为记录页。

## 资料整理工作台

整理流程按“原件及来源定位 → 识别/输入文本 → 草稿卡片”呈现。桌面端优先并排查看，手机端用分步或切换视图保持同一逻辑顺序。音视频首版没有自动转写时，原件仍可查看，用户可手工输入内容并建卡；不能因缺少中间文本而使原件无法整理。具体视觉样式与操作细节后续迭代。

## 当前开放问题

- 记录页与快捷编辑框的详细布局及关闭后去向；
- Executor View 是独立模式还是独立导航树；
- Desktop 与 Android 导航如何共享信息架构但允许不同布局。

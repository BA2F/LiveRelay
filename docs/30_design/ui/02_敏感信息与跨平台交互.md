## 敏感信息交互方向

需要考虑：

- 显示/隐藏；
- 复制；
- 必要时重新认证；
- 自动锁定；
- 截图；
- 后台状态。

这些交互必须服从 Security 的运行时边界。

首版密码库条目的 Secret 默认遮挡。Vault 已解锁时，用户可主动显示或复制单个条目密码，不要求每次复制都重新认证；密码库批量导出前则需再次验证用户身份。导出格式和再次验证的具体方式仍待设计。

## 跨平台方向

长期方向：

> Mobile Capture + Desktop Organize

移动端更适合拍照、快速录入；Desktop 更适合批量整理和管理。

## 当前开放问题

- 单个 Secret 显示多久后自动遮挡；
- 剪贴板交互；
- Android/Desktop 自动锁定差异；
- Executor View 中敏感信息的默认展开级别。

## 敏感信息交互方向

需要考虑：

- 显示/隐藏；
- 复制；
- 必要时重新认证；
- 自动锁定；
- 截图；
- 后台状态。

这些交互必须服从 Security 的运行时边界。

## 跨平台方向

长期方向：

> Mobile Capture + Desktop Organize

移动端更适合拍照、快速录入；Desktop 更适合批量整理和管理。

## 当前开放问题

- Secret Reveal 是否需要每次重新认证；
- 剪贴板交互；
- Android/Desktop 自动锁定差异；
- Executor View 中敏感信息的默认展开级别。

# UI/UX 设计总览

> 状态：已确认  
> 版本：0.5
> 最后更新：2026-10-03
> 依赖文档：无


## 当前阶段原则

第一阶段 UI 允许工程化、粗糙，但必须能够完整操作核心链路。

正式版阶段普通 UI 去除开发说明，保留必要的操作帮助与真实能力状态。2026-10-03 第一切片已经接入首次设置、我的、可保存外观偏好和宽屏侧栏；内部 AppearanceTokens 与 CardBrowserBuilder 分离主题参数和档案浏览布局，尚非第三方皮肤公共契约。莱茵风格三维外观后续开发，不作为本轮交付。

UI 不得把：

- 业务规则；
- SQL；
- 密码算法；

直接塞进按钮回调。

## 后期方向

核心链路稳定后再进行视觉重构。

Apple HIG 可作为层级、留白、字体、简洁、隐私透明和可访问性的参考，但 Android 不做像素级 iOS 仿制。

后期视觉重构主要替换表现层/设计系统，不应重写 Life Core、Vault 或 AI Privacy。

完整 Design System 旧思考已移动到本次语义清理归档，不作为当前 MVP 设计待办。

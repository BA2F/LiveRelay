## 当前核心概念

目前出现过的核心概念包括：

- Account
- Secret
- Asset
- Relationship
- Location
- Document
- Source
- HandoffPolicy
- Recipient
- LifeState

Revision、Provenance、来源可信度和 Current State 的定义统一由 `provenance/` 负责，本目录不再重复定义。

- 哪些类型属于首版最小模型。

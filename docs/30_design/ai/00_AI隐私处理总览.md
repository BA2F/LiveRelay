# AI Privacy 总览

> 状态：已确认  
> 版本：0.8
> 最后更新：2026-10-12
> 依赖文档：capture/02_OCR坐标与人工字段标注.md


## 核心原则

普通云 LLM 不能对真正的密文直接推理。

LiveRelay 首版采用：

```text
本地敏感标记
→ Token 替换
→ 脱敏但可读文本
→ 云 LLM
→ 结构化 JSON
→ Schema / Token 校验
→ 本地 Rehydration
```

云 AI 整理是用户主动启用的可选路径，不能在用户未启用时自动上传。即使不用云 AI，用户仍应能够手动整理资料和创建卡片。原始照片、录音、录像及密码原文不因启用该路径而上传。

外发确认按 2026-10-12 确认的跨端原则执行（桌面重设计决策单第 5 节），不再每轮弹窗：

- 首次向某个 AI 服务发送内容、首次发送附件：各拦一次，说明“以后这类内容默认发送”。附件按原始内容发送、不做敏感替换，单独成一次确认；
- 日常发送：把将发送的内容常驻在输入区旁边，所见即所发。面板展示的就是实际外发范围（脱敏文本、附件清单与转写）；
- 授权按设备本地的服务记录（服务标识 + 本机地址），与 AI 服务配置同处设备存储，不进入加密库、不随整库搬运；可在 AI 服务设置里收回，下次发送重新确认；服务地址变化视为新服务；
- 远程语音上传与附件同一规则：首次向该语音服务上传音频前确认一次，之后按页面显示的地址与模型直接上传。

无论哪条路径，只发送本次由用户选中的资料经本地脱敏后的内容，不默认搜索或发送整个 Vault；未确认的首发不发送。每轮发送前仍校验本轮内容、附件与配置代次没有变化，变化则拒绝并提示重新检查。

统一术语为 **AI Privacy**；旧术语不再作为当前设计语言使用。

## 边界

- 原始照片、音频和 Secret 原文默认不上传；
- Token Map 只在本地；
- AI 是不可信外部处理器；
- AI 只做结构化整理，不成为事实源；
- 人工标注类别由 `capture/02_OCR坐标与人工字段标注.md` 定义。

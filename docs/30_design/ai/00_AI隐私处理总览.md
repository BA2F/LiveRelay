# AI Privacy 总览

> 状态：已确认

> 依赖文档：capture/02_OCR坐标与人工字段标注.md


## 核心原则

普通云 LLM 不能对真正的密文直接推理。

LiveRelay 首版采用：

```text
本地敏感标记
→ Token 替换
→ 脱敏但可读文本
→ 云 LLM
→ 结构化 JSON
→ Schema / Token 校验
→ 本地 Rehydration
```

云 AI 整理是用户主动启用的可选路径，不能在用户未启用时自动上传。即使不用云 AI，用户仍应能够手动整理资料和创建卡片。原始照片、录音、录像及密码原文不因启用该路径而上传。

每次云 AI 调用前，以类似本地 Agent 申请权限的方式向用户请求授权；首版只提供“允许本次 / 拒绝”，不提供“始终允许”。请求需说明本次用途、目标 Provider 与所选资料的外发范围，不把强制通读整篇脱敏文本作为唯一确认界面；具体展开预览方式仍待设计。仅允许发送本次由用户选中的资料经本地脱敏后的内容，不默认搜索或发送整个 Vault。未授权不得发送。

统一术语为 **AI Privacy**；旧术语不再作为当前设计语言使用。

## 边界

- 原始照片、音频和 Secret 原文默认不上传；
- Token Map 只在本地；
- AI 是不可信外部处理器；
- AI 只做结构化整理，不成为事实源；
- 人工标注类别由 `capture/02_OCR坐标与人工字段标注.md` 定义。

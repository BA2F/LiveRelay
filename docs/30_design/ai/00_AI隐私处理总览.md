## 核心原则

普通云 LLM 不能对真正的密文直接推理。

LiveRelay 首版采用：

```text
本地敏感标记
→ Token 替换
→ 脱敏但可读文本
→ 云 LLM
→ 结构化 JSON
→ Schema / Token 校验
→ 本地 Rehydration
```

统一术语为 **AI Privacy**；旧术语不再作为当前设计语言使用。

## 边界

- 原始照片、音频和 Secret 原文默认不上传；
- Token Map 只在本地；
- AI 是不可信外部处理器；
- AI 只做结构化整理，不成为事实源；
- 人工标注类别由 `capture/02_OCR坐标与人工字段标注.md` 定义。

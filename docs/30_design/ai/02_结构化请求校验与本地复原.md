# 结构化请求、校验与本地复原

> 状态：讨论中

## AI 请求

当前方向是请求中明确：

- Prompt；
- Schema；
- Context；
- Provider metadata。

目标是限制 AI 只做结构化整理。

## AI 返回

优先 JSON Schema。

返回结果需要区分：

- 事实；
- 推断；
- 来源引用。

## 本地校验

至少校验：

- Schema；
- 类型；
- 未知字段；
- 非法 Token；
- 缺失 Token；
- 重复 Token。

## Rehydration

Token Map 只在本地使用，云端不获得映射表。

只有通过校验的结构化结果才能在本地执行 Rehydration。

## 当前开放问题

- 首版 JSON Schema 的具体字段；
- AI 是否允许删除/合并输入信息；
- 缺失 Token 的失败策略；
- 结构化结果如何写入 Provenance。

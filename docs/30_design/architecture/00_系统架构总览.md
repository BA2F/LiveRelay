# 系统架构总览

> 状态：已确认  
> 版本：0.5  
> 最后更新：2026-09-23  
> 依赖文档：无


## 当前结论

LiveRelay 当前推荐采用 **Local-first 模块化单体 + 轻量 Clean Architecture**。

空间上的核心关系已在 MVP 中实现为：

```text
UI
↓
Application
↓
Life Core
↓
Vault / Capture / AI Privacy / Handoff 等能力
↓
Database / Files / Cloud / OS
```

时间维度另外处理：

- 用户生命状态；
- 信息版本与修订；
- 信息释放状态；
- 来源历史。

当前逻辑能力包括：UI、Application、Life Core、Vault、Crypto、Database、Blob、Backup、Provenance、Capture/OCR、AI Privacy、AI Provider、Lifecycle、Handoff、Platform。

当前 Flutter 路径映射见 `architecture/01_系统分层与模块边界.md`。逻辑能力已经落地，但仍不等于独立 package 或对外冻结模块。

## 知识所有权

- 模块边界与依赖规则：本架构子域；
- 业务实体、LifeState、Release Policy：`domain/`；
- Revision、来源、冲突、Current State：`provenance/`；
- Vault、密钥、数据库与 Blob 安全边界：`security/`；
- 人工字段标注类别：`capture/02_OCR坐标与人工字段标注.md`；
- AI Tokenization 与结构化处理：`ai/`；
- Executor/失能/身故流程：`handoff/`。

## 当前真正开放的问题

- 出现桌面端后，Application/Core 是否值得拆为独立 package；
- Capture 的平台插件部分与纯 Dart 工作流如何进一步分离；
- 真实远程交接、同步和身份核验将引入哪些新信任边界；
- 大文件流式加密和桌面安全能力是否需要 Native/FFI。

# 本地优先与跨平台架构

## Local-first 原则

- 数据主副本在本地；
- 原始资料不依赖云端才能存在或恢复；
- 云 AI 只获得用户允许的脱敏内容；
- 离线时核心 Vault 应可用；
- 未来同步只是便利层，不是系统真实性的唯一来源。

## 跨平台方向

首版候选 Flutter，同一工程覆盖 Android 与 Desktop。

计划共享：

- 大部分 UI；
- 业务模型；
- AI Privacy；
- Vault 相关逻辑。

平台特有能力通过 Adapter 隔离，例如：

- Android Keystore；
- Biometric；
- Camera；
- File Picker。

当前不采用“先做 PC 再整体移植到手机”的路线。

## 当前开放问题

- Flutter 工程的分层和目录映射；
- Android/Desktop 能力抽象的实际粒度；
- 哪些安全能力必须通过 Native/FFI 实现。

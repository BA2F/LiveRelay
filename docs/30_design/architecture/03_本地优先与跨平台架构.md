# 本地优先与跨平台架构

> 状态：已确认  
> 版本：0.5  
> 最后更新：2026-09-23  
> 依赖文档：无


## Local-first 原则

- 数据主副本在本地；
- 原始资料不依赖云端才能存在或恢复；
- 云 AI 只获得用户允许的脱敏内容；
- 离线时核心 Vault 应可用；
- 未来同步只是便利层，不是系统真实性的唯一来源。

## 跨平台方向

首版已经采用 Flutter/Dart 单工程，当前交付 Android App。Desktop runner 可以由 Flutter 工程承载，但桌面平台能力和 UI 尚未交付。

当前已共享：

- 业务模型与生命周期规则；
- AI Privacy；
- Vault 密钥、Blob、备份和 Repository 抽象；
- Application 用例编排的大部分纯 Dart 逻辑。

平台特有能力通过端口或基础设施适配隔离，例如：

- Android Keystore；
- Biometric；
- Camera；
- File Picker。

当前不采用“先做 PC 再整体移植到手机”的路线。

Android 当前使用真实平台插件完成 Keystore/Biometric、Camera、File Picker、录音和媒体播放。Google ML Kit OCR 当前只支持移动平台；桌面端需要替代实现。

## 当前开放问题

- 桌面端安全存储、系统生物识别和本地 OCR Provider；
- 桌面大文件流式加密是否需要 Native/FFI；
- 哪些表现层组件真正适合共享，需由桌面端真实使用验证；
- 未来同步只能作为可选便利层，协议和冲突模型尚未设计。

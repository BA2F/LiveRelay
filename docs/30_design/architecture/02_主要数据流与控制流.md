## 当前核心数据流

### 采集与 AI 整理

```text
照片
→ 原图进入加密保存
→ 本地 OCR
→ 人工字段标记
→ Tokenization
→ 云 AI
→ JSON / Token 校验
→ 本地 Rehydration
→ 加密保存
→ Provenance
```

### 交接

```text
Vault 解锁
→ LifeState
→ Release Policy
→ Executor View
```

## 当前恢复原则

- 失败不能静默丢资料；
- AI/OCR 失败时保留原始资料；
- Token 不匹配时拒绝复原；
- 导出失败不能破坏原 Vault；
- 写入和迁移需要可恢复。

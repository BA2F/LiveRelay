# 原始资料与转换链

> 状态：讨论中  
> 版本：0.4  
> 最后更新：2026-09-06  
> 依赖文档：provenance/00_来源追踪体系总览.md


## 当前结论

需要能够表达：

- Source；
- Transformation；
- Derived Record；
- 原始资料中的具体锚点。

锚点候选包括：

- 页码；
- OCR Bounding Box；
- 音频时间片。

来源类型候选包括：

- 本人输入；
- 原始文件；
- OCR；
- ASR；
- AI 推断；
- 本人确认；
- 协助者录入；
- 家属后续补充。

## 当前开放问题

- Source 与 Transformation 的最小数据结构；
- 多次转换如何串成链；
- Bounding Box / 页码等锚点如何统一表示；
- Source 类型与“可信度”是否解耦。

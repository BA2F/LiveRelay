# 原始资料与转换链

> 状态：讨论中  
> 版本：0.5
> 最后更新：2026-09-19
> 依赖文档：provenance/00_来源追踪体系总览.md


## 当前结论

需要能够表达：

- Source；
- Transformation；
- Derived Record；
- 原始资料中的具体锚点。

锚点候选包括：

- 页码；
- OCR Bounding Box；
- 音频时间片。

来源类型候选包括：

- 本人输入；
- 原始文件；
- OCR；
- ASR；
- AI 推断；
- 本人确认；
- 协助者录入；
- 家属后续补充。

用户可以明确删除原始资料，但删除前需提示哪些卡片将失去该原件。删除后相关卡片保留“原件已删除”的来源状态，不再声称可打开或精确核对该原件；保留必要的来源关系和删除记录。原件内容与可能残留的衍生文本如何分别清除，仍需设计。

## 当前开放问题

- Source 与 Transformation 的最小数据结构；
- 多次转换如何串成链；
- Bounding Box / 页码等锚点如何统一表示；
- Source 类型与“可信度”是否解耦。
- 原件删除时 OCR/转写中间产物、缓存和历史版本的清理边界。

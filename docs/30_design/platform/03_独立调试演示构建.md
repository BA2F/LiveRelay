# 独立调试演示构建

> 状态：本机工程实现
> 日期：2026-10-03
> 依据：正式版范围16、人类明确补全本机调试演示模式

默认 `lib/main.dart` 不导入 `lib/development/` 或 `main_debug_demo.dart`，不建立模拟身份、调试控制器或演示开关。App／我的页面仅有可选注入端口；未注入时连点版本号不会打开任何隐藏权限。版本号连续七次点击（三秒间隔内）仅向注入的 DevelopmentControls.activate 发出请求；控制器具体实现只在独立 entrypoint 的依赖图中。

启动演示采用 `flutter run -d linux -t lib/main_debug_demo.dart`，或 `flutter build linux --debug --target lib/main_debug_demo.dart`。每次建立新的系统临时 `liverelay-demo-*` 根目录，并显式传给 app_composition；Vault、AI 设置、语音、命令临时文件、身份、接收者和偏好都位于这个根目录，不读取正常应用 support 目录。演示退出后的临时加密目录保留，不自动递归删除其他路径。

内置虚构所有者／接收者、两个信息卡片、一个无效账号、真实本地加密库，以及一份仅含演示卡片摘要的已验证接收者包。所有者密码 `Demo-only-2026`、接收者密码 `Recipient-demo-2026`，仅是演示材料。没有 API Key、默认设备指纹或网络交付。所有者和接收者绑定及包仍通过同一挑战／签名／HPKE 流程生成，不以绕过安全检查的示例对象冒充实装。

窗口有始终可识别的“独立演示 · 虚构资料”小浮层，折叠／展开后可调整模拟时间、切换所有者锁定／解锁及接收者入口、注入 Active／Incapacitated／Deceased 状态、调整平台能力矩阵。浮层可滚动。时钟注入 SqliteVaultRepository 的卡片／修订／生活状态等时间和洞察查询；真实交接传输时间、密码派生和挑战验证仍由安全服务处理，不用模拟时钟取得额外授权。能力矩阵只改变本次演示的能力展示，硬件保护仍不可用，不模拟成功的真实系统指纹。

该入口不进入发行 `main.dart`。Linux 演示 bundle 独立保存在本轮本地制品目录，随后重新构建标准 release；Android 正常构建不指定演示 target。不会把 debug 偏好写入正常设备偏好，也不会让演示生活状态调用真实自动交接。

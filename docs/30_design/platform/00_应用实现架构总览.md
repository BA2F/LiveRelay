## MVP 技术基线

- Flutter 3.47.2 / Dart 3.13.2；
- 单个 Flutter package：`work/code/live_relay/`；
- Android 首发，`minSdk 24`、`targetSdk 36`；
- Material 3 表现层；
- 核心领域和端口使用纯 Dart，平台插件限制在基础设施层或组合根；
- Python、C/C++ 和 FFI 均未进入当前 App 运行链路。

Application 层由 `AppController` 负责会话密钥生命周期和完整用例协调，不直接实现 SQL、密码算法、OCR 或网络协议。

## 工程目录映射

| 路径 | 职责 |
|---|---|
| `lib/presentation/` | Material 3 页面、对话框、Design System 原子组件 |
| `lib/application/` | 解锁会话、用例编排、错误和 UI 状态协调 |
| `lib/core/domain/` | 卡片、凭据、原件、来源、生命状态和释放策略语义 |
| `lib/core/ports/` | Vault、OCR、AI、生物识别内部替换端口 |
| `lib/core/security/` | 中文词组口令和 Vault 密钥封装 |
| `lib/infrastructure/` | SQLCipher、Blob、备份、OCR、AI、CSV 和 Android 适配器 |
| `lib/main.dart` | 依赖组合根，不承载业务规则 |

当前尚未为了“模块化外观”拆成多个 Dart package。先保持依赖方向和可替换端口，待出现独立复用或独立发布需求再物理拆包。

## 第三方依赖原则

成熟库优先，但关键数据格式、接口和迁移能力不能被单一小众库绑死。

MVP 关键依赖包括：

- `drift` + `sqlite3` SQLCipher：结构化加密存储；
- `cryptography`：Argon2id、AES-GCM、HKDF、HMAC；
- `flutter_secure_storage` + `local_auth`：Provider 配置和 Android 生物识别密钥槽；
- `google_mlkit_text_recognition`：端侧中文 OCR；
- `image_picker`、`record`、`just_audio`、`video_player`：采集和回看；
- `http`：OpenAI-compatible HTTPS Provider；
- `archive`：`.lvault` ZIP 容器。

后续依赖升级仍需记录：

- 版本；
- 许可证；
- 替代方案；
- 是否影响 LifeVault 格式。

## 当前边界与开放问题

- Android 生物识别实现已编译并接入，实体设备硬件验证尚未完成；
- 桌面端尚未实现媒体、Keystore/生物识别等平台适配器；
- `Application` 和 `core` 是否拆成独立 package，等待第二个客户端或独立复用需求；
- 大文件当前在内存中加解密，单个 Blob 限制 256 MB；流式加密未来可能需要 Native/FFI；
- `cryptography_flutter` 当前构建仍使用旧式 Kotlin Gradle Plugin 接入，未来 Flutter 升级前需要更新依赖。

## 当前技术方向

- 首版候选 Flutter/Dart；
- Python 用于自托管 AI/OCR 或实验工具；
- C/C++ 未来可用于 secure memory、流式加密、本地模型，但不作为首版核心前提。

Application 层负责完整用例协调，不直接实现 SQL 或密码算法。

## 第三方依赖原则

成熟库优先，但关键数据格式、接口和迁移能力不能被单一小众库绑死。

重要第三方库需要记录：

- 版本；
- 许可证；
- 替代方案；
- 是否影响 LifeVault 格式。

## 当前开放问题

- Flutter 内部工程结构尚未形成真实方案；待专题设计时再创建对应文档，而不是预留占位文件；
- Flutter 工程实际分层；
- Application 是否成为独立 package/module；
- 哪些能力需要 Native/FFI。

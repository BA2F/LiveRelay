# 本地语音输入

> 状态：当前实现记录，手机资源与硬件验收待完成\
> 日期：2026-10-03，采集流收敛 2026-10-12\
> 依赖：capture/00_采集系统总览.md；ai/00_AI隐私处理总览.md

语音输入现在有实际页面与本地识别链路，复用原件、来源和待整理卡片，不新增数据库 schema。已有录音原件保存功能继续存在。

## 2026-10-12 采集流收敛

录音和语音输入在手机上是同一条路：记录页只保留「录音」一个语音入口，录 16 kHz 单声道 WAV（最长 60 秒）并作为原件加密保存，这一次保存就是采集阶段唯一的保存动作。保存完成后可以直接「转写为文字」——识别在已入库的原件上进行，不再另存一份音频，核对后的文字存为关联该原件的待整理草稿；也可以稍后从原件详情的「转写为文字草稿」进入。原来的独立「语音输入」入口保留为语音识别与模型管理页（桌面语音会话听写继续用它），不再作为手机上的第二个采集入口；页面上「暂不自动转写」的提示随之删除。

此前手机端语音页在识别时默认且不可见地另存一份音频原件，属于同一次录音两次落库，已取消。远程语音服务首次上传音频前确认一次，之后按页面显示的地址与模型直接上传，见 [AI Privacy 总览](../ai/00_AI隐私处理总览.md)。

## 本人操作链路

首次明确选择下载或导入官方 SenseVoice 包，看到安装状态、下载进度、失败信息和取消入口。安装后录制最长 60 秒，或导入 16 kHz 单声道 PCM16 WAV。原件先写入 AES-GCM Blob 并登记来源卡片，再在工作 isolate 用本地模型识别。识别失败保留原件；成功后本人检查或修改文字，点击保存后创建与原件关联的待整理草稿，来源标为“本地语音识别 · 本人校对”。只有手动输入而没有音频来源时，使用本人输入来源，不虚构录音。

音频不上传；将识别文字交给云 Agent 是另外一次明确选取、标注和授权。模型下载只取得公开权重。临时录音和文件选择器缓存关闭后清理；启动清理已知 WAV 缓存。锁定清空页面文字，晚到识别结果不展示或自动入库。导入用户指定的 WAV 不删除原文件。

## 实现和资源边界

- `SpeechProvider` 是同 package 内部端口，`SpeechService` 管理状态、串行操作和可控字节清理；`LocalSenseVoiceProvider` 管理安装与原生识别。
- 依赖锁定 `sherpa_onnx 1.13.8`，模型为 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`；压缩包约 156 MiB，模型约 229 MiB，界面提示预留 1 GB 空间。APK 不包含模型权重，包含 sherpa 原生运行库。
- 官方 GitHub HTTPS 下载仅允许已知 GitHub 资源域跳转；没有库文件、音频或服务密钥参与下载。压缩输入上限 320 MiB、展开 tar 上限 512 MiB，最多 200 个归档成员，只向固定文件名写入 `model.int8.onnx` 与 `tokens.txt`，拒绝链接、重复文件与越限。
- 在工作 isolate 流式展开，成功后将 staging 安装到应用支持目录 `live_relay/speech/`。安装标记核对文件大小，失败清理 staging；取消展开在工作结束后阻止提交，不声称能立即终止解压 isolate。
- WAV 上限 2 MiB／60 秒，严格检查 PCM16、单声道、16 kHz 和块边界。原生识别使用 CPU 两线程，流／识别器 finally 释放，清除可控 PCM 与 WAV 副本。不保证插件、FFI 或操作系统内存中所有副本被物理擦除。
- Android、Linux、Windows 有实现接线；其他平台返回不支持。模型状态检查失败不会阻止密码解锁。模型卸载不删除加密原件或已经保存的草稿。

## 实际验证与限制

Linux 使用真实官方模型及包内公开中文 WAV，完成流式安装与原生识别。返回“开饭时间早上9点至下午5点。”，证明链路可运行，也说明仍需人工校对。仓储／控制器回归验证语音草稿与加密原件的关联重开后仍在。

Android 与 Linux release 构建记录见本轮交付；没有实体 Android 录音／内存／延迟验证，也没有 Windows 运行验证。当前不支持任意音频重采样、长录音分段或时间片来源；不把录音保存、本地 ASR 和云 Agent 混为一种能力。

实现依据：[官方模型说明](https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html)、[官方 Flutter/Android ASR](https://k2-fsa.github.io/sherpa/onnx/flutter/asr-android.html)。

## 首版输入与完整整理链路

首版允许直接输入文字，拍照或从相册选取照片，以及录音、录像。文字、照片、录音和录像都需作为原始资料进入加密保存，并在资料列表中可见；不能因为暂时没有自动识别能力就丢弃音视频原件。

目前要求完整跑通的自动识别链路仍以照片为主：

```text
照片 / 相册导入
→ 原图进入加密保存
→ 本地 OCR
→ 文本 + Bounding Box
→ 用户框选/涂抹并标记敏感字段
→ AI Privacy
```

录音、录像首版先满足采集、加密保存和回看原件；语音转文字、视频内容提取及其自动整理留到后续。手动文字无需 OCR，可直接进入整理草稿流程。音视频原件将来产生的文本或卡片仍需追溯到原件及相应时间片。

PDF/文档导入、ASR 与视频内容识别不阻塞首版。

## 边界

- Capture 负责获得输入和人工标注；
- OCR 负责图片 → 文本与坐标；
- Capture 不决定释放权限；
- Capture 不定义 Revision；
- AI Privacy 只消费 Capture 已产生的标注/文本，不重新定义人工标注类别。

## 当前开放问题

- 原图进入加密 Blob 的准确时机；
- 录音、录像原件的大小限制、失败恢复与加密写入方式；
- Camera/相册导入失败时如何恢复；
- Capture 与 OCR 最终是否一个物理模块。

# 采集系统总览

> 状态：讨论中  
> 版本：0.4  
> 最后更新：2026-09-06  
> 依赖文档：无


## 当前 MVP 链路

```text
照片 / 相册导入
→ 原图进入加密保存
→ 本地 OCR
→ 文本 + Bounding Box
→ 用户框选/涂抹并标记敏感字段
→ AI Privacy
```

首版只要求把这条图片链路跑通。

PDF/文档导入和 ASR 已移出当前活跃设计，不阻塞 MVP。

## 边界

- Capture 负责获得输入和人工标注；
- OCR 负责图片 → 文本与坐标；
- Capture 不决定释放权限；
- Capture 不定义 Revision；
- AI Privacy 只消费 Capture 已产生的标注/文本，不重新定义人工标注类别。

## 当前开放问题

- 原图进入加密 Blob 的准确时机；
- Camera/相册导入失败时如何恢复；
- Capture 与 OCR 最终是否一个物理模块。

# 威胁模型与安全边界

> 状态：讨论中  
> 版本：0.4  
> 最后更新：2026-09-06  
> 依赖文档：security/00_安全设计总览.md


## 当前威胁候选

- 手机或电脑丢失；
- Vault/备份文件泄露；
- 普通恶意 App；
- 云 AI；
- 家庭内部滥用；
- 离线暴力猜密码；
- 数据篡改；
- 日志/剪贴板/截图泄漏；
- Root/Hook/注入；
- 用户死亡后无法恢复数据。

## 下一步真正要完成的内容

威胁模型需要把上述威胁分成：

- 首版必须防；
- 首版尽量防；
- 明确无法防；
- 后续版本处理。

这一步会直接约束 LifeVault、密钥、运行时和 Handoff 设计。

## 已发布 MVP 核心模型（v1）

- 随机 Vault Master Key 真正加密数据；
- 主密码通过 memory-hard KDF 产生解锁/封装所需密钥；
- 修改主密码原则上只重新封装 Master Key，不重加密全部数据。

首版密码库与其他卡片共用一个 LifeVault 的主密钥和解锁状态，不另设独立的密码库主密码。这不妨碍未来把密码库能力复用为独立应用；在已解锁会话中显示或复制单条密码不要求每次重新认证。`.lvault` 批量导出前要求重新输入主密码；独立明文密码批量导出尚未实现。

## MVP 密码槽参数

- VMK：`Random.secure()` 生成 32 bytes；
- Salt：16 bytes；
- KDF：Argon2id v19，memory 19 MiB、iterations 2、parallelism 1、输出 32 bytes；
- Password Slot：AES-256-GCM，nonce 12 bytes，AAD `LiveRelay/VaultMasterKey/v1`；
- Header formatVersion：1；算法和参数随 Header 保存，便于未来读取旧格式。

长期可以增加不同 Key Slot，例如：

- Password；
- Device；
- Recovery；
- Handoff。

## K1 新格式底层评估

2026-10-03 新增 Header v2 evaluation suite、随机独立 LRR1 恢复编码、密码／恢复各保护分支秘密 B、VMK 解封与整 Header MAC；内部 reader 支持 v1/v2，默认创建仍为 v1。新格式不复用旧设备完整 VMK 槽，也不能包入 `.lvault` v1。具体字节与密钥依赖见 [内部工程规格](08_Header_v2底层格式与恢复编码.md)。

本片只交付底层评估：中文恢复、保存／回输、重设日常凭证、设备因素、新所有者备份和最弱 Android profile 验收尚未完成。正式默认创建不因底层测试通过而自动切换。旧库不升级，既有日常密码或指纹行为保持。

## 生物识别

Android Keystore 保存/使用设备密钥，并可以要求指纹、人脸或设备凭据认证。

生物识别是日常便利入口，不是唯一恢复钥匙。

概念上，指纹不是可输入、可导出的秘密密钥；它是设备本地的认证方式，授权使用受 Android Keystore 保护的设备密钥。MVP 使用 `flutter_secure_storage` 的 Android biometric storage namespace 保存 Base64 编码 VMK，要求 strong biometric 且每次读取重新认证。启用时必须先重新输入主密码解封 VMK；清除配置会删除设备槽。该流程已编译和模拟器走查，但仍需实体设备验证。

## Passphrase Generator

中文随机词组口令已用纯 Dart 集成。解析词表时会剔除重复拼音键或重复展示词，安全词表少于 1000 项则拒绝启动生成；使用 `Random.secure()` 无放回抽样，并返回按实际候选数计算的熵。当前仍需补齐词表来源和再分发授权记录。

生成器产出的是供人输入的口令，不直接生成或充当 VMK；规范化后的拼音形式进入上述 Argon2id KDF。

双输入边界已实现：接受逐词分隔的确切汉字或不区分大小写的拼音，也接受能够唯一分词的连续汉字；不接受任意同音异字。逗号、顿号、中点、连字符和多余空白会规范化为词间空格。歧义拼音/汉字条目在载入阶段剔除。

已确认的适用范围：上述汉字/拼音双输入仅适用于由中文词组生成器创建的口令。创建或修改 Vault 主密码时，用户可以选用生成器产生的词组口令，也可以自定义主密码；自定义主密码不进入拼音转换流程。密码库条目中保存或导入的密码保持原值，也不进入该流程。词组口令经 KDF 参与解锁随机 Vault Master Key，不直接充当该主密钥。

Passphrase Generator 与 Recovery Phrase 是两个不同概念。

用户还提出将中文词组口令用于未来的交接/权限凭证；具体角色和密钥关系尚未设计，不能因原型可生成口令就视为交接机制已完成。

## 当前本机主流程

主界面新建采用独立 Header v3；日常密码／可选文件／可选设备任一或全部，独立 R 旁路；全库换 VMK 而非仅修改槽图。旧库须本人主动升级。安全设置及受限恢复、新备份、身份与接收者包已接通本机，格式和具体边界见 [安全10](10_本机安全流程与格式v3.md)、[安全11](11_本机交接与分层备份格式.md)。设备因素继续使用 K2 的只保护份额及每次强生物识别规则。上述软件实现不代替 Android 真机性能／授权、正式安全复核及发行验收。

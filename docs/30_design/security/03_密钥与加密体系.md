# 密钥与加密体系

## 当前核心模型

- 随机 Vault Master Key 真正加密数据；
- 主密码通过 memory-hard KDF 产生解锁/封装所需密钥；
- 修改主密码原则上只重新封装 Master Key，不重加密全部数据。

长期可以增加不同 Key Slot，例如：

- Password；
- Device；
- Recovery；
- Handoff。

## 生物识别

Android Keystore 保存/使用设备密钥，并可以要求指纹、人脸或设备凭据认证。

生物识别是日常便利入口，不是唯一恢复钥匙。

## 恢复

首版可以只实现：

- 主密码；
- `.lvault` 导出恢复。

长期再设计 Recovery Key、纸质材料、多接收人等。

## Crypto Agility

需要允许未来升级：

- KDF；
- 对称算法；
- 参数；
- 密钥封装；
- 格式版本。

## Passphrase Generator

用户已有基于 chinese-diceware 修改的中文随机词组密码生成器，可作为候选。需要检查 CSPRNG、词表最终 Token 唯一性、熵和词数。

Passphrase Generator 与 Recovery Phrase 是两个不同概念。

## 当前开放问题

- 首版 KDF 和参数；
- Master Key/Key Slot 的具体封装格式；
- Android Device Key 如何与 Master Key 连接；
- 首版是否需要真正 Device Slot；
- Password 更换流程。

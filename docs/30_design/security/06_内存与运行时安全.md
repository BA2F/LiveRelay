## 明文内存原则

目标是**缩短明文暴露**，不是承诺“内存中绝不出现明文”。

首版方向：

- 不一次解密整个 Vault；
- 按需解密 Secret；
- 页面关闭后尽快释放；
- 不把 Secret 写日志。

Flutter/Dart 的 GC-managed String 不能保证立即清零，这是首版限制。未来可以考虑 C++ secure buffer。

启动快捷记录时，必须先解锁 Vault 再开放文字、拍照、录音和录像输入；首版不设计未解锁时的明文暂存队列。

## 其他泄漏面

需要考虑：

- 剪贴板；
- 截图；
- 后台缩略图；
- Crash report；
- Debug log；
- 输入法；
- 屏幕录制。

首版至少保证不记录秘密日志。

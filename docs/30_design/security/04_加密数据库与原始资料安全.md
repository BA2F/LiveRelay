## 加密 SQLite

首版要求 SQLite 在磁盘页面级整体保持密文。

未持有正确密钥时，不应让普通数据库工具直接看到：

- 表结构；
- 记录数量；
- 时间等结构化元数据。

具体采用 SQLCipher、VFS 或其他成熟方案仍需比较。

## 原始资料 Blob

照片、PDF、音频、视频落盘前加密。

磁盘只保存随机 ID 的密文 Blob；真实文件名、描述等信息放在加密数据库中。

原始资料需要能够随设备迁移、备份和导出。

# 安全设计总览

> 状态：已确认

> 最后更新：2026-09-06  
> 依赖文档：无


## 当前安全地基

首版安全方向已经明确：

- 运行时 SQLite 磁盘页面整体加密；
- 原始资料作为独立加密 Blob；
- 主密码经 KDF 解锁随机 Master Key；
- Android 生物识别作为便利入口，而不是唯一恢复机制；
- `.lvault` 单体导出；
- 记录算法/格式版本；
- 尽量缩短明文在内存中的存在时间；
- 不自创密码算法。

## 安全目标

同时考虑：

- 保密性；
- 完整性；
- 可用性。

LiveRelay 的可用性尤其重要，因为 Owner 可能失能或死亡。

## 明确非目标

- Root/系统完全失陷时，不能承诺保护正在显示或正在使用的明文；
- 首版不承诺防物理胁迫；
- 不做“量子密钥分发”。

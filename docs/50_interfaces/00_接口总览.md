# 接口总览

> 状态：已确认  
> 版本：0.4  
> 最后更新：2026-09-23  
> 依赖文档：无


当前已经存在可替换的 **MVP 内部端口**，但仍没有面向第三方或跨 package 冻结的公共契约。真实 Dart 类型以 `work/code/live_relay/lib/core/ports/` 为准。

| 内部端口/边界 | 当前输入输出 | 实现与状态 |
|---|---|---|
| `VaultRepository` | 卡片、修订、关系、Blob 元数据、凭据、策略、状态和统计的异步读写 | `SqliteVaultRepository`；已在 App 使用 |
| `OcrProvider` | image bytes + original name → `OcrResult` | Google ML Kit 中文 OCR；Android 已验证 |
| `AiProvider` | endpoint + API key + model + redacted text → structured response text | OpenAI-compatible HTTPS；单元测试通过，真实服务待联调 |
| `BiometricKeyStore` | availability / save VMK / read VMK / clear | Android Keystore + local_auth；实体设备待验证 |
| AI Privacy Core | OCR lines + marks → redacted text/token map；response → validated drafts | 纯 Dart；Token 完整性测试通过 |
| Vault Key/Blob/Archive 格式 | password slot、Blob v1、`.lvault` v1 | 已落盘使用；格式演进必须带版本和迁移 |

## 当前契约规则

- UI 和具体 Provider 不能绕过 Application 直接读取 VMK；
- AI Provider 只接收调用方提供的脱敏文本，不获得数据库、原图或 Token Map；
- OCR 只产生候选结果，不决定事实状态或释放权限；
- 所有持久化调用为异步，Repository 负责修订历史和审计写入；
- Blob、Vault Header 和 `.lvault` 格式必须显式版本化，不能用依赖库私有格式替代产品格式；
- 新客户端出现前，端口允许在同一 package 内演进；一旦跨 package 复用，需冻结错误语义、兼容性和契约测试。

## 何时创建独立公共契约文件

一个公共契约至少明确以下内容后才创建独立 Markdown：

- 目标和非目标；
- 输入/输出及类型；
- 错误语义；
- 同步/异步要求；
- 生命周期/幂等性要求（如适用）；
- 安全与隐私约束；
- 版本和兼容性；
- 最小契约测试。

当前端口已有真实实现，但尚未达到对外公共 API 的兼容承诺；不要仅复制 Dart 签名制造两套事实源。

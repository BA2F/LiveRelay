## 项目是什么

LiveRelay 是本地优先人生信息连续性与交接系统。第一版面向年轻用户本人，长期支持适老化和家庭协助。

## 当前阶段

产品定位和主要原则已经形成，首个 Flutter/Android MVP 已在 `work/code/live_relay/` 跑通并通过 `4b4032e` 纳入 Git 基线。当前进入实现收敛、真机验证和安全复核阶段。

已有 `mvp-0.1` 与 `mvp-0.2` 预发布里程碑 Tag 及原 APK 发布记录；它们不是正式签名或商店发布版本。内部端口已经用于 MVP，但尚未冻结为对外公共契约。

## 当前实现

- Flutter/Dart 单工程，Android API 24+；
- Argon2id + AES-256-GCM VMK 封装 + SQLCipher schema v4；
- AES-GCM Blob、`.lvault` v1、卡片/历史/拆分组合、密码库；
- 图片/录音/录像采集和回看、端侧中文 OCR；
- AI Privacy Tokenization、单次授权和 OpenAI-compatible Provider；
- Active/Incapacitated/Deceased 演示、释放策略和 Executor View；
- 轻量加密记录、待整理、独立搜索/筛选、来源/全部原件、回收恢复及锁定/首次使用备份恢复；
- 精确授权预览、独立本机交接模拟、中文 AI 外发检查与手工整理；
- 2026-10-02：38 项测试、静态分析、Android 16 完整 UI 回归和 Release APK 构建通过；明暗主题、320dp/200% 字体、键盘和主要读屏标签有回归验证。
- 实施证据见 `work/paper/uiux-review-2026-10-01/实施与验证交付.md`；测试使用独立包名/资料库，真实 AI 与实体生物识别仍待验证。

## 已确认的重要方向

- Local-first；
- SQLite 磁盘页面整体密文；
- 原始资料独立加密 Blob；
- `.lvault` 单体导出方向；
- 原始资料优先和 Provenance；
- 云 AI 默认只见脱敏后的 Token 文本；
- 家庭协助不等于查看权限；
- 接口/模块可替换，但不预造空契约；
- 产品思想和设计知识完整保留，执行层主动压缩。

## 当前优先事项

1. 真机指纹和媒体权限验证；
2. 真实 AI Provider 联调；
3. 迁移/恢复样本与中断测试；
4. 正式签名、可复现构建和正式发行版本 Tag；
5. 收集使用反馈后再决定下一轮产品范围。

继续遵守渐进式阅读、无占位文档、稳定契约不由叶子任务私改等治理规则。

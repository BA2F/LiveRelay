# 通用 Agent 项目工作区初始化说明

> 状态：参考规范  
> 版本：0.2  
> 最后更新：2026-09-06  
> 依赖文档：无


本文件用于以后从零创建其他项目，不属于 LiveRelay 日常运行文档。

## 一、第一性原则

先区分稳定信息角色，再创建目录：

```text
project/
├── README.md
├── AGENTS.md
├── docs/
├── notes/
├── records/
├── memory/
├── tasks/
├── handoffs/
├── work/
├── templates/
├── skills/
├── scripts/
└── archive/
```

不要因为“要写 PPT”“要加功能”“要做某个实验”就新增顶层信息角色。

## 二、docs 的通用抽象

```text
docs/
├── 00_governance/
├── 10_overview/
├── 20_spec/
├── 30_design/
├── 40_components/
├── 50_contracts/
├── 60_quality/
├── 70_plan/
└── 90_references/
```

具体项目允许将 `spec/components/contracts` 改为更自然的领域词。例如软件产品可使用 `product/modules/interfaces`。

## 三、初始化时不要创建大量空壳

初始最小集合通常只需要：

- README；
- AGENTS；
- governance 的少量规则；
- 项目总览；
- 当前 spec；
- 当前 design 总览；
- 当前上下文；
- tasks 看板；
- work 成果区。

其他目录和文档只有在出现真实独立职责时再创建。

## 四、初始化流程

1. 明确项目目标、边界、当前阶段；
2. 创建稳定顶层信息角色；
3. 写 README 和 AGENTS；
4. 写 governance；
5. 建立总览和当前 spec/design；
6. 将已有原始资料放 notes/references；
7. 将关键决策写 ADR；
8. 生成当前项目上下文；
9. 建 tasks 看板；
10. 后续随着设计成熟再创建 components/contracts。

# 复杂版到当前实例的迁移原则

> 状态：当前有效  
> 版本：0.2  
> 最后更新：2026-09-06  
> 依赖文档：无


本次迁移遵循：

1. 产品思想、设计、安全、研究、ADR 不因“简化执行上下文”而删除；
2. Governance 从二十多篇合并成五篇高密度规则文档；
3. 模块执行层从统一八篇压成默认三篇；
4. 接口继续独立，作为跨模块契约；
5. 当前 memory 合并成一篇，旧记忆留历史快照；
6. 六周不是长期信息角色，因此“当前阶段”文件不以六周命名；
7. 报告和 PPT 不建立新知识目录，只作为 work 输出；
8. 通用项目初始化规范移动到 archive，不干扰 LiveRelay 日常执行；
9. 原复杂版 ZIP 原样保存在本目录，保证可以完整回溯。

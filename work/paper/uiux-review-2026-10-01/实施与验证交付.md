## 授权规则保持及精确预览

下表描述当前实际行为，不引入新的摘要或字段授权。授权选择页会按具体记录逐项显示相同输出。

| 等级 | 卡片实际输出 | 密码条目实际输出 |
| --- | --- | --- |
| 保持私密 | 无标题/正文 | 无名称/内容 |
| 只知道有这条信息 | 标题 + 存在提示，无正文 | 名称 + 存在提示，无账号/密码 |
| 基本信息 | 标题 + 正文前 80 个 UTF-16 单元，超过时追加省略号；短正文全部显示 | 名称 + 账号和网址；无备注/密码 |
| 完整内容 | 标题 + 完整正文 | 名称 + 备注；备注为空回退账号；无网址/密码 |
| 含密码/密钥 | 标题 + 完整正文 | 名称 + 账号 + 密码，密码默认遮挡 |
| 含原始资料 | 当前规则仍是标题 + 完整正文，本机预览不发放原件文件 | 当前规则仍是名称 + 账号 + 密码，密码默认遮挡；不发放原件文件 |

“基本信息”说明明确是截取正文开头，并非本人选定的摘要。保留原有不完全对称的卡片/凭据规则，不借改界面改变释放范围。交接仍为本机模拟及演示执行人，不包含真实接收者、自定义交接摘要、字段级授权或真实自动交接。

## 数据和备份兼容性

- SQLCipher schema 仍为 v4，Vault Header/Blob 仍为 v1，`.lvault` 仍为 v1；本次没有新增 schema 迁移。
- 来源、历史、回收恢复和导出记录复用已有表/审计记录；编辑追加同卡片新修订，原件、原来源、旧正文与旧密码历史保留。
- 恢复先 staging，验证口令、清单认证和加密数据库；展示认证后的备份时间、内容数量、回收区与替换影响。恢复不合并；运行失败有原库回退，成功后清理失败不再撤销已完成恢复；恢复后关闭导入设备的指纹槽。
- Android 导出暴露 `cryptography_flutter` 原生 HKDF 空 salt 导致的 Empty key 异常。修复为显式 32 字节零 salt；与旧省略/空 salt 的 HMAC 等价。测试直接用旧纯 Dart HKDF 算法计算 MAC 并核对一致，格式版本及认证字节不变。
- 导出时间只在系统选择器报告保存成功后写入；不声称已拥有可靠设备外备份。取消选择不写成功记录。导出记录属于当时本机审计，恢复旧备份只恢复其已有审计状态。

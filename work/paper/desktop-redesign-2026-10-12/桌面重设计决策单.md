## 0. 背景与已确认方向

旧桌面（codex/desktop-workbench）以工程可行性为驱动：停靠画布、浮动面板、独立进程窗口与为它们服务的 IPC。逐屏核对后的问题不在"选择桌面范式"，而在只实现了 IDE 的家具、没有实现其语法：

- 列表行内嵌完整编辑器（浏览与编辑合一），同一张卡可在列表、标签、浮动面板、独立窗口四处同时编辑、无主次；
- 半成品机制：命令面板不能用键盘选择；关标签无待保存检查；独立窗口为另一进程、另一套主题（紫色）、部分视图降级，且"恢复为新修订"存在真 bug（作用于列表第一张卡）；
- 无"待整理"收件箱——"手机采集→桌面整理"这条主产品动线的落点在桌面不存在。

已由本人确认的方向（2026-10-12）：

1. 桌面走 Obsidian / VSCode 一类正统桌面软件范式，要求"语法完整"，不是家具复刻；
2. 独立窗口（独立进程 + IPC 方案）删除，不再保留（VSCode 的同应用多窗口是同进程，不采用其进程外形态）；
3. 双端分工：手机 = 多模态采集 + 简单整理；桌面 = 采集 + 整理 + 完整 Agent；
4. 互通先做 **C 模式**：整库搬运（数据线 / 局域网 / WebDAV 当 U 盘），导入即整库替换并明确提示，不做合并裁决；**B 模式**（按卡片修订合并）以后另立课题，不预留半套；
5. 授权/确认状态模型重新整理（跨端），细节另立设计，施工顺序见第 8 节第 3 步。

本决策单是后续施工与文档回写的唯一基准。

## 1. 三区结构（一期）

- **左栏 · 资料库导航**（可折叠）：待整理 / 全部卡片 / 原件 / 密码 / 回收；顶部搜索框与"新建"。此栏只承载"浏览"：行 = 标题 + 状态 + 时间。
- **中央 · 标签页编辑区**：一个对象一个标签。对象包括卡片、原件、助手对话、关系图、变更、设置等视图；列表类不再开标签。
- **底部 · 状态条**：保留现有形态（左下"本地加密资料库"，右下保存状态、失败可点重试）。
- **右栏一期不做**；二期再给"来源 / 历史 / 引用"这类随当前标签变化的面板。

## 2. 对象规则

- 列表回到"列表"：一行只显示标题、状态、时间；点击才在标签里打开编辑。
- 废止"列表行内嵌完整编辑器"与"同一卡多处同时编辑"。CardEditSessions 的多缓冲保留为引擎能力，界面不再暴露并发编辑入口。
- 关闭标签：内容无变化直接关；防抖保存在途时显示"待保存"提示并等待完成（不允许无提示丢改动）。

## 3. 一期砍掉（宁缺勿半成品）

- 独立窗口全家桶：独立进程、IPC 通道、会话/语音桥接、紫色主题、降级视图、相关测试、window_manager / screen_retriever 依赖；
- 工作台内浮动面板；
- 拖拽停靠画布与四向分屏（标签拖拽排序保留；分屏二期再议）；
- 命令面板（Ctrl+Shift+P）——二期以完整键盘支持回归；
- 启动时"选择你的工作台"预设；
- 扩展管理界面入口（扩展注册表内核保留，入口先收进设置，界面二期回归）。

## 4. 一期新增（正统桌面标配）

- **右键菜单**：列表项、标签、编辑区通用，按对象给出（打开、重命名、移入回收、复制引用等）；
- **快捷键基线**：Ctrl+N 新建、Ctrl+F 搜索、Ctrl+P 按标题快速打开卡片、Ctrl+S 立即保存、Ctrl+W 关闭标签、Ctrl+L 锁定；
- 恢复上次打开的标签与会话；
- 主窗口最小尺寸；
- 所有危险动作统一走第 5 节确认原则。

## 5. 跨端确认原则（方向，细节另立）

确认的粒度跟"新增的风险"走，不跟"动作次数"走：

- 首次向某 AI 服务发送、首次携带附件离线外发：拦截一次并说明"此后这类内容默认发送"；
- 日常发送：把"将发送的内容"常驻显示在输入区旁（所见即所发），不再每轮弹窗；
- 不可逆动作（永久清除、整库替换恢复）：明确确认；可撤销动作（移入回收）：直接执行 + 撤销入口；
- 只改无关设置时不得连带要求重输恢复凭证（现状反例：仅改指纹开关也强制走恢复凭证确认流程）。

手机与桌面共用此原则。

## 6. 收件箱（待整理）

- 左栏第一位，命名"**待整理**"（与手机端用词一致）；
- 汇集三类到达物：手机传入的、桌面直接记的、Agent 建议生成的草稿；
- 是"手机采集 → 桌面整理"动线的落点，也是 C 模式互通的对接点。

## 7. 旧代码去留（初判）

**保留（引擎/能力，换壳继续用）：**
CardEditSessions 编辑缓冲与防抖保存、保存状态机；AgentConversation 及建议/计划/回执逻辑；卡片编辑器字段组件；RelationsView 画布；原件预览（PDF / 媒体）；扩展注册表；测试基建（integration_test 夹具模式、证据截图机制）。

**删除（随第 3 节）：**
dock_surface、detached_workbench、native_window_host、window_conversation_bridge、window_speech_bridge、IPC 通道、工作台预设、拖拽图标栏。

**重写：**
桌面外壳（三区骨架、标签系统、右键/快捷键）；卡片列表组件（剥离内嵌编辑器）；顶部栏；desktop_workbench_test 大部重写（可迁移用例保留）。

# 总体目标架构来源索引

日期：2026-10-04；设计版本：v1.0。图源 cell 的 `evidence` 属性与 [完整 JSON 索引](design-index.json) 使用相同来源编号。

## 系统总图的九类内容

| 内容 | 主图位置／关键 cell | 其他视图补充 |
|---|---|---|
| 组件或模块 | `t01-ui-*`、`t01-app-*`、`t01-core-*`、`t01-storage-*`、`t01-cloud*` | 应用图给出职责与端口，技术图给出框架与基础设施 |
| 关系或连接 | `t01-rolesToUI`、`t01-uiToApp`、`t01-appToCore`、`t01-coreToData`、`t01-externalAI`、`t01-externalCloud`、`t01-deliverEnvelope` | 业务图的价值链与应用图的依赖方向 |
| 分层或视图 | 交互呈现、业务应用、领域与安全内核、加密数据与基础设施 | 业务、应用、数据、技术四张全项目视图 |
| 边界 | 本地客户端、连续性服务、外部服务、安全治理边界 | 应用图中的四个独立会话／信任域 |
| 接口和协议 | HTTPS、Provider、仓储／平台端口、插件／FFI | 技术图的 HTTPS/TLS、JSON、WebDAV、文件与模型接口 |
| 数据流和处理 | 采集与识别→组织确认→来源／状态→加密保全→授权交接 | 数据图完整展开来源、派生、对象、持久化与消费 |
| 符号和注释 | 分层颜色、虚线边界、页脚箭头图例、设计版本 | 所有页面采用一致图例与术语 |
| 安全和治理 | 身份权限、VMK所有权、隐私、可信审计、云端信任边界 | 数据图的存储归属、应用图的隔离、技术图的密码技术 |
| 非功能性需求 | 底部的可用性、可靠性、性能、可维护与扩展、长期使用 | 技术图的工程治理与非功能设计 |

## 关键节点与连线依据

| 节点／连线 | 表达的设计 | 来源 |
|---|---|---|
| `t01-actors-*` | 本人、家庭协助、指定接收者与服务运维角色 | P01、P02、S01 |
| `t01-client`、`t03-client` | 跨端本地客户端；一个Flutter package内的逻辑模块 | A01、A02、A03 |
| `t01-uiToApp`、`t01-appToCore` | 从表现到用例编排，再到领域与安全规则 | A02 |
| `t03-infraDomain`、`t03-composition` | 适配器实现核心端口，组合根选择实现并注入 | A02 |
| `t01-app-0`、`t01-app-1` | 资料采集、识别、人工与AI整理 | P02、I01、R01 |
| `t01-app-2`、`t04-secret` | 密码凭据与专门Secret字段 | D01 |
| `t01-app-3`、`t04-revision`、`t04-source` | 原件与来源链、修订、当前状态、冲突可解释 | R01、R02 |
| `t01-app-4`、`t01-app-5`、`t04-policy` | 独立身份、接收者绑定、对象／字段／历史／原件范围 | D02、S01、S03 |
| `t01-app-6`、`t04-exchange-0`、`t05-security-2` | 备份、独立恢复、受限重设与全库换钥 | S01、S02、S03 |
| `t01-ai`、`t01-externalAI`、`t04-exchange-2` | 本次批准文本外发，敏感行Token化，本地保管映射 | I01 |
| `t01-govern1`、`t03-isolation-*`、`t05-trust` | Owner VMK、Recipient私钥与外部服务隔离 | S01、S02、S03、I01 |
| `t01-cloud0`、`t01-externalCloud` | 云端／自部署加密备份与密文同步 | P02、S01 |
| `t01-cloud1`、`t01-cloud2`、`t01-deliverEnvelope` | 提醒与宽限、预授权信封调度、接收者私钥解密 | P02、S01 |
| `t01-cloudRule` | 调度控制投递；不托管Owner VMK或恢复材料；无响应不是生命状态证明 | P02、S01 |
| `t04-storage-*` | 主库、原件、Recipient身份和云端密文的不同所有权 | A03、S01、S03 |
| `t05-clientRuntime-*`、`t05-applicationRuntime-*` | Flutter/Dart、平台插件、FFI、本地识别和受控Agent | P02、A02、T01 |
| `t05-security-*`、`t05-persistence-*` | KDF、AEAD、签名／HPKE、SQLCipher、Drift与归档事务 | S02、S03、T01 |
| `t01-quality-*`、`t05-engineering-*` | 离线可用、可恢复、资源预算、模块端口、长期可迁移 | P02、A03、S01、T01 |

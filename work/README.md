# 成果目录使用说明

> 状态：当前有效
> 版本：0.5
> 最后更新：2026-10-24
> 依赖文档：无

- `code/`：代码。
- `diagrams/`：架构图和流程图。
- `data/`：实验和测试数据。
- `paper/`：阶段报告、项目报告和论文草稿。
- `slides/`：汇报和答辩材料。
- `exports/`：最终导出成果。`exports/release-artifacts/` 被 Git 忽略，是安装包的发布暂存目录。

安装包的长期下载入口是 [GitHub Releases](https://github.com/BA2F/LiveRelay/releases)。制品身份和发布流程见 [RELEASING](../RELEASING.md)。

报告和 PPT 是项目事实的输出视图，不反向成为新的事实源。

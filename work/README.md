# 成果目录使用说明

> 状态：当前有效\
> 版本：0.4\
> 最后更新：2026-10-02\
> 依赖文档：无


- `code/`：代码；
- `diagrams/`：架构图、流程图；
- `data/`：实验和测试数据；
- `paper/`：阶段报告、项目报告、论文草稿；
- `slides/`：汇报和答辩；
- `exports/`：最终导出成果；`exports/release-artifacts/` 是被 Git 忽略的安装包发布暂存目录。安装包的长期下载入口是 [GitHub Releases](https://github.com/BA2F/LiveRelay/releases)，制品身份及流程见 [RELEASING](../RELEASING.md)。

报告、PPT 等是项目事实的输出视图，不反向成为新的事实源。

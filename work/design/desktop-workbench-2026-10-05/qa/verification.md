# 交互验证记录

2026-10-05，通过 Codex 内置浏览器实际操作；不是 Flutter 测试或后端联调。

已核对：

- 首次选择资料工作台；重开记住选择。
- 原始文字展开、图片加载；5 秒合成音频与 6 秒合成视频可播放。
- 来源在新标签与分屏打开，窗口组合并；标签拖到另一个窗口组。
- 助手底部停靠、浮动拖动、返回右侧，助手工作台中央布局。
- 模型切换，添加模拟提供方及其模型；语音条停止后回填示例文字。
- 编辑 Agent 建议并确认保存；重开后卡片与来源保留，显示家庭收纳及仅本人。
- 手动编辑卡片；恢复旧内容生成新修订；关系节点打开原始资料。
- 本地文字文件关联到已有卡片；重开后临时文件消失而卡片保留。
- 明暗主题；独立原始资料页面的媒体渲染。浏览器实际弹出新窗口受其设置影响，未确认所有浏览器行为。
- 390 × 844 窄屏资料视图：页面宽度 390，无整页横向溢出，一个可见窗口组；点击助手可以进入输入面板。
- JavaScript 通过 `node --check`。关键交互阶段浏览器未报告控制台错误。

截图：`desktop.jpg` 为正式演示的 4 张示例卡片；`assistant.jpg` 与 `mobile.jpg` 来自隔离 QA 数据，包含测试保存的第 5 张卡片。

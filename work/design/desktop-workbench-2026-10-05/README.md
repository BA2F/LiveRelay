# LiveRelay 桌面工作台交互 Demo

日期：2026-10-05。状态：讨论用前端原型；不是 Flutter 应用功能，也不冻结窗口模型、分类模型或接口。

本次人类明确的要求：

- 首次打开由用户选择资料工作台或助手工作台。
- 卡片包含标题、总结与原始文字／图片／录音／录像的链接。
- 来源能在卡片里展开查看或播放，也能跳转到原始资料视图。

## 打开

在当前目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，访问 <http://127.0.0.1:8766>。也可直接用浏览器打开 `index.html`；本地服务器更适合媒体播放和多窗口演示。

没有框架或安装依赖，页面使用 HTML、CSS 与 JavaScript。所有资源在 `assets/` 中，无外部网络请求。

## 可以操作的内容

- 首次选择与记住起始工作台；从顶部切换资料／助手布局。
- 卡片浏览、搜索、分类、原位展开来源、新标签查看来源。
- 图片查看、音频播放、视频播放；本地选择图片、音视频和文字资料。
- 标签切换、关闭、重排、拖到另一个窗口组；分屏与合并。
- 助手停靠到左右／底部、移到中央标签、浮动拖动／缩放、独立浏览器窗口。
- 独立打开资料视图；多浏览器窗口共享已保存的示例卡片修改。
- 关系节点拖动与点击，来源链接跳转。
- 变更操作列表、内容前后比较、恢复旧内容为新修订。
- 手动创建／编辑／确认卡片；模拟 Agent 回应、编辑建议、确认保存与收纳。
- 多提供方配置、模型搜索切换、语音条计时、取消与文字回填。
- 明暗主题与小屏布局。

## 演示边界

- 不连接真实 API，不访问 LiveRelay 的真实 Vault，也不读取现有 API Key。
- 提供方连接状态、模型回应、语音转写都是模拟；麦克风按钮不录音。配置中的 Key 输入不保存。
- 示例修改保存在浏览器 localStorage，**不是加密资料库**；只用虚构内容评估界面。
- `location.svg` 为位置示意图；WAV 为合成提示音，WebM 为合成测试画面，均不是用户的真实原件。图片查看器可通过本地文件选择查看真实照片，但只用于本次浏览器会话。
- 本地选择的文件只在本次会话使用，刷新后需要重新选择；文件内容不会上传。
- 浮动窗口包含页面内浮动和浏览器弹出窗口两种方式。独立窗口是否允许，由浏览器设置决定。
- 本次收纳与可见范围使用最小演示，保持仅本人；没有模拟真实资料交付。Agent 密码录入／转换仍按此前决定后置。

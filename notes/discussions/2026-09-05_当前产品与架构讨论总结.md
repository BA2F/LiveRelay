# 当前产品与架构讨论总结

> 状态：历史讨论总结  
> 版本：0.1  
> 最后更新：2026-09-05  
> 依赖文档：无

截至 2026-09-05 的主要演进：

1. “身后事 App”扩展为人生信息连续性与交接系统；
2. 明确所有年龄可用、老年价值峰值；
3. 第一版用户收敛为年轻人本人；
4. P0：物品位置、账号/密码/资产、失能有限释放、逝者→生者；
5. AI 是整理层，原始资料优先；
6. 引入 Provenance；
7. 本地 OCR + 人工敏感标记 + Tokenization + 云 AI；
8. 技术方向从 KMP 重新评估后倾向 Flutter；
9. Vault 收敛为整库加密 SQLite + 独立加密 Blob + `.lvault` 导出；
10. 当前不急于 C++ Core，先设计接口和模块；
11. 建立渐进式披露、多 Agent、接口冻结、ADR、handoff 的项目治理。

正式结论以 docs 和 ADR 为准。

# 会话与恢复职责解耦

> 状态：实现与 Linux 验证完成，Android／Linux release 构建通过\
> 日期：2026-10-03\
> 授权：人类同意先小范围解耦，再继续独立恢复凭证

## 范围和边界

从当前未提交 K0 实现继续，保留全部已有改动。抽出资料库会话（密钥、数据库打开关闭、锁定与清理）、备份核对／导出／恢复流程，集中组装平台实现。页面继续使用 AppController；它保留忙碌／错误提示、解锁数据投影及业务操作协调。

不改变 Header／Blob／`.lvault` v1、schema v4、密码或指纹任一解锁、恢复事务的提交与回滚规则。既有端口签名保持兼容。新内部边界仅服务单 package，不形成新的公共稳定契约。独立恢复、AND、接收者包属于下一轮。

## 实施区域和验收

- application 新建会话／备份服务，控制器委托敏感资源管理；VMK 不暴露给页面或 AI。
- infrastructure 的组合入口负责默认实现、数据库工厂、设备路径／词表及启动缓存准备；main 使用此入口，测试可替换依赖。
- 复用已有 K0 故障回归与 Linux 原生恢复，并针对新会话边界补充必要的资源释放验证。
- 顺序执行静态分析、完整 Flutter 测试、Linux 原生恢复集成、Linux／Android release 构建。
- 回写架构／模块／接口实际归属、看板和上下文；不 commit、push 或发布，不访问日常用户库。

# Windows 桌面适配（main 合并后重新落地）

> 状态：已完成（本地分支 `codex/windows-adaptation`，起点 `8d887b6`，未推送）
> 日期：2026-10-18
> 来源：本人 2026-10-18 指令「最新的github仓库里面的版本可能在不同分支拉取下来适配windows」
> 依赖：证据见 [Windows 桌面适配验证](../../docs/60_quality/2026-10-18_Windows桌面适配验证.md)

## 背景

远端已把 `codex/desktop-rebuild`、`codex/desktop-workbench`、`codex/formal-foundation` 合并进 `main` 并删除，`main` 成为唯一分支（`8d887b6`）。10-14 的 Windows 修复落在当时的 `codex/desktop-rebuild` 上，分支已不存在，`main` 里没有 `file_commit.dart`，13 处仍直接调用 `rename`。

## 范围

允许修改：文件提交路径及其调用点、相关用例、Windows 验证与设计文档回写。

禁止修改：稳定契约与公开格式、`pubspec` 依赖、Android／Linux 行为、本人真实资料库与凭据、Tag 与已发布制品。

## 修改

- 新增 `lib/core/storage/file_commit.dart`：先原子 `rename`，平台拒绝且 sidecar 仍在时退化为覆盖写入／递归复制后删除暂存；目录提交拒绝覆盖已存在目标。
- 13 处调用点接入：`recoverable_file`(1)、`vault_restore_transaction`(7)、`encrypted_blob_store`(2)、`file_device_preferences_repository`(1)、`local_sense_voice_provider`(1)、`directory_transfer_medium`(1)。
- 用例：恢复事务崩溃安全用例改用 SDK 自带 `dart`；Linux 播放后端 PDF 用例按平台跳过；新增 Windows 生产入口建库用例；`file_commit_test` 增加默认跳过的跨卷退化用例；WebDAV 死链超时 2 秒改 15 秒（断言不变）。
- 文档：CHANGELOG 未发布段、平台能力设计、测试与验证策略、应用 README、验证记录。

## 验收

`flutter analyze` 无问题；`flutter test` 317 通过、7 跳过、0 失败；Windows 生产入口用例与 `flutter build windows --release` 通过；跨卷用例在指定第二块磁盘后 4 项全过，直接 `rename` 报 error code 17。

属模块内部实现变化、契约不变，按 [决策与变更流程](../../docs/00_governance/03_决策与变更流程.md) 第 2 节更新设计与 Handoff，不需要 ADR。

Windows 指纹、密钥环存储、接收者身份、交接与备份恢复、release 签名与分发；未在 Linux 复跑。

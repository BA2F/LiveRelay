## 目标与输入

在现有 Flutter MVP 上实现正式版第一切片，不破坏既有加密库与备份。输入为现有实现和已确认的产品方向；输出为可运行代码、测试、设计回写和真实 Handoff。

必读：AGENTS.md；产品 16；领域 02；UI 01；平台架构 00；安全 03（沿用现有密钥，不改协议）。复杂任务按主题读取，不扩展扫描。

## 范围与依赖

允许修改 Flutter 单 package 中的领域公共卡片抽象、应用摘要投影、设备偏好存储、呈现和平台能力模型，以及相关测试、Linux／Windows 启动工程。内部端口仍是内部契约。同步更新领域／导航设计、任务看板、项目上下文及 Handoff。

不修改 SQLCipher schema、主密钥／备份格式、现有授权模型，不把单体所有者备份当成接收者交接包。中文与自定义日常密码沿用原方案，不提前实现未经设计的多方式组合或独立恢复密钥。不实现三维皮肤、在线服务器／WebDAV、模型下载、任意命令运行或第三方插件加载。无需理解商业化与纪念模块。

本轮将中文保留为唯一已完成语言，其他语言入口显示尚未提供，不产生半翻译界面。首次设置支持系统／浅色／深色和中等／大字，创建与恢复调用已有真实流程；中断后继续，已有库升级不重新创建。“我的”先显示当前本机所有者身份及设置；接收者真实认证与自定义身份资料后续完成。

## 验收与必须验证

- 一般卡片与密码卡片共享基础抽象；卡片页能查询和打开密码卡片，密码库仍操作同一条记录，历史／回收／授权保持兼容。
- 摘要投影不持有 Secret，搜索不会因密码命中；密码默认遮盖，显式查看／复制复用既有受控 UI。
- 外观偏好重启可恢复；写入失败不标记已保存；损坏偏好文件不会导致重建现有 Vault；首次创建／恢复成功后才结束设置。
- 五个导航入口在手机可用；宽屏使用侧栏；320dp、200% 文字、明暗主题及桌面布局不溢出。
- 尚未接入的平台能力保留入口并显示明确状态，避免调用不存在的插件。外观令牌与卡片浏览器接口不依赖仓库或加密。
- 运行 flutter analyze、完整 flutter test、Linux 构建；生成 Windows runner 并记录 Windows 构建需在 Windows 验证。Android 构建按环境验证。执行 scripts/check_structure.py。

发现权限或加密契约不足时停止该相关功能实现，记录具体问题；其他独立基础工作继续。完成后更新任务状态，Handoff 区分实测、未验证和后续工作，不以“方向已确认”宣称功能已交付。

## 现场反馈修正：创建密码校验

2026-10-03 人类操作后提出：创建密码应提前说明要求、实时显示符合项和两次输入一致，不能沿用解锁错误。修正保持原有最少 8 个字符规则与格式，允许修改创建页、共用长度校验及相关测试。验收短密码不触发创建，合格／一致对号可见，改动密码后重新确认保存，旧的解锁错误不进入创建页；完成后构建 Linux 供继续操作。

现场反馈修正已实现；静态分析无问题，53 项完整测试通过，结果补记于同一 Handoff。

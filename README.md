> 状态：当前有效

LiveRelay 是一个面向中文社会环境的本地优先人生信息连续性与交接系统。

当前仓库处于**设计期**：产品思想和部分系统原则已经形成，但尚无正式代码、真实开发 Task、Handoff 或冻结公共契约。目录结构不代表设计完成度。
